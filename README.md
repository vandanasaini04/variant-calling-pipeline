# S. aureus Variant Calling Pipeline

## Overview
End-to-end NGS variant calling pipeline for Staphylococcus aureus WGS data.

## Tools Used
- FastQC - quality control
- Trimmomatic - read trimming
- BWA-MEM - read alignment
- SAMtools - BAM processing
- FreeBayes - variant calling

## Dataset
- Input: S. aureus WGS paired-end reads (SRR8359173)
- Reference: S. aureus USA300 genome (GCF_000013425.1)

## Results
- 58,548 variants identified

## How to Run
Open the .ipynb file in Google Colab and run cells sequentially.
